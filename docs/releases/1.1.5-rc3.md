# Nrfr 1.1.5-rc3 — 三星 SIM2 APN 查找修正

已使用既有簽章在 S25 覆蓋安裝 `com.github.nrfr.s25`，版本 `1.1.5-rc3-s25`、
versionCode 14。測試裝置使用 Android 17、One UI 9 與 Nightzuku，免 root、無重啟。

rc2 的 SIM2 錯誤「原 APN 與選取狀態無法確認」發生於提交前。三星對該 SIM
以 RIL 業者類型決定固定 APN 查找代碼。該代碼下的三筆 APN 才是設定畫面及
數據服務正在使用的項目。用訂閱代碼查到的三筆 APN 則全未被使用。

rc3 依三星每張卡的查找方式核對原 APN 與選取，並用相同的代碼處理新 APN 和
還原。已確認使用固定代碼的路徑能保留原列及目標代碼下的既有列；套用後仍會
逐一核對原數據 APN、設定清單與選取 ID。

## S25 實測

- 用 SIM2 原來失敗的預設，勾選「修改 SIM 電信業者代碼」並提交。回讀確認
  目標代碼生效，三筆原數據 APN、設定清單及原選取逐欄一致。SIM1 已有的覆寫、
  完整 APN 資料及選取保持一致。
- SIM2 新增 APN 可儲存且可見。新項目使用三星實際查找的代碼，只屬於 SIM2
  的目前清單，原選取保持一致。兩卡同時處於覆寫狀態時，綁定 SIM2 的 DNS 和
  HTTPS 204 通過。刪除測試 APN、關閉再開啟行動數據後取得新連線，兩項再次通過。
- 無重啟還原 SIM2 後，雙卡代碼、APN 與原選取全欄位符合基準，包含 SIM1 已有的
  覆寫。原預設數據卡的綁定 DNS／HTTPS 204 通過。
- 76 項單元測試、Lint 和 APK 建置通過。此次沒有針對 SIM2 執行清除 App 資料
  或全部 APN 重設，其他韌體組合仍待實測。
