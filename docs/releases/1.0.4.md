# Nrfr 1.0.4 相容性測試版

修正 Android 17 透過 Shizuku 套用 SIM 國家碼與電信業者名稱的相容性，並更新 Android SDK 與正體中文介紹。

- 套用後核對設定與 SIM 國家碼。
- 支援 Shizuku 免 root 操作。
- 使用 Android 17 SDK 建置。

## 安裝與還原

此版本使用測試簽章，建議改用[最新正式版](https://github.com/alzpqm/Nrfr/releases/latest)。升級正式版前，請先還原設定、依提示重啟，再移除測試版；不同簽章無法直接覆蓋安裝。

Android 16／17 的臨時覆寫可能在重啟、換卡或重載後失效。解除安裝不會自動還原系統設定；「還原設定」可能清除其他工具對同一 SIM 的 CarrierConfig 覆寫。

維護署名：**Nrfr 維護團隊**。
