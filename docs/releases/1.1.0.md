# Nrfr 1.1.0 功能測試版

新增 SIM 電信業者代碼設定、備份與還原，並提供正體中文介面。

- 支援 5／6 位 MCC＋MNC，保留前導零。
- 提供 177 組代碼、45 個國家／地區的可搜尋預設。
- 顯示 SIM、訂閱資料與連線網路的讀取值。
- 支援 Android 17 與 Shizuku 免 root 操作。

## 安裝與功能範圍

此版本使用測試簽章，建議改用[最新正式版](https://github.com/alzpqm/Nrfr/releases/latest)。升級正式版前，請在舊 App 還原設定、依提示重啟，再移除測試版；不同簽章無法直接覆蓋安裝。

代碼修改僅針對 SIM 讀取值，不修改訂閱資料、連線網路或基地台 MCC／MNC。套用可能重載電信設定，完成後請確認通話與行動數據正常。

Android 16／17 的臨時覆寫可能在重啟或重載後失效。解除安裝不會自動還原系統設定，亦會刪除本機備份，請先還原並依提示重啟。「還原設定」可能清除其他工具對同一 SIM 的 CarrierConfig 覆寫。

維護署名：**Nrfr 維護團隊**。
