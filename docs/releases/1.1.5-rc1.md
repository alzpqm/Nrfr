# Nrfr 1.1.5-rc1 — S25／Nightzuku 候選版

本次發布獨立套件 `com.github.nrfr.s25`（版本 `1.1.5-rc1-s25`、versionCode 12），
與真機實測 APK 相同，可覆蓋既有 S25 測試版並與原 1.1.4 並存。
沿用既有 S25 測試簽章；原正式版金鑰已遺失，兩者不能互相覆蓋。

## 修改

- 改用 Nightzuku 官方 API／provider 13.2.1；本次 S25 使用既有 Nightzuku r53，免 root。
- 保留 MCC／MNC 修改功能，IMSI 參數保持 null。以所選 SIM 的 carrier 規則與原 APN
  關聯處理篩選；不複製 APN，不反覆覆寫合成業者 current。
- 修正 Samsung APN 單列更新拒絕非空 where 的錯誤；新增 APN 原位校正，保留 ID、
  連線參數及原選取，提交前檢查衝突並完整回讀。
- 用 Nightzuku shell UserService 在 App 資料目錄外保存三組還原紀錄；原子寫入與
  回讀先於系統修改。清除 App 資料後，正常重開可自動恢復紀錄及 APN 維護。
- 完成還原後清除所屬紀錄；保留不含 SIM 紀錄的空文件，避免舊本機備份復活。

## 本次真機證據

Android 17／One UI 9 的 S25，實際勾選「修改 SIM 電信業者代碼」，保留 MCC、只改 MNC：

- 清除候選版資料後正常重開，三份紀錄逐字恢復，沒有手動匯入。
- 新增 APN 存檔可見；同一 ID、其他連線欄位與原選取保留，另一卡完整 APN／選取不變。
- 修改後及行動數據關閉再開啟後，指定 SIM 的行動 Network DNS、HTTPS 204 均通過；
  重連取得新 Network handle，驗證排除 Wi-Fi 與另一張 SIM。
- 無重啟還原後，兩卡原代碼、完整原 APN／選取符合基準，測試規則及三組紀錄清除，
  維護服務停止。原預設數據卡、國家碼／名稱與 USB 亮屏設定已恢復。
- 71 項單元測試、Lint 與候選版建置通過。原始診斷及簽章私鑰留在本機，不隨發布上傳。

## 使用與限制

在這台 Android 17 裝置上啟動 **Nightzuku**，授權 **Nrfr S25 Diagnostic**。
改 MNC 期間保留 Nrfr 的 APN 維護服務。清除 App 資料後，須先正常開啟 Nrfr，確認
Nightzuku 可用並完成讀取，再新增 APN；尚未驗證強制停止後不重開仍能維護。
還原後先核對原代碼、APN 與行動數據，本次實測無需重啟。

全部 APN 原廠重設、電話重啟後的持久性、長期穩定性及其他裝置／系統組合未驗證。
此為已通過上述有限路徑的候選版，不宣稱所有 APN 或行動數據問題已解決。
診斷套件會在裝置自身的 App 外部專用目錄保存私人 APN 快照，請勿公開原始檔案。
