# Nrfr 1.1.5-rc4 — 三星 IMS 註冊狀態與套用選擇

S25 使用者回報兩張 SIM 勾選「修改 SIM 電信業者代碼」後都失去 IMS 註冊。
在 Android 17／One UI 9、Nightzuku 環境，本機日誌確認兩卡仍有 IMS APN，
三星 IMS 卻使用覆寫後的業者代碼推導註冊網域。SIM1 收到 SIP 500，SIM2 收到 SIP 404。
逐張還原時，SIM2 的註冊改回從原代碼推導，在 SIM1 還維持覆寫時就已重新註冊成功。

裝置內三星 IMS 程式的網域推導分支讀取 SIM 代碼。其提供的 IMS 設定寫入介面需要
三星的簽章權限，本機免 root 委派未持有此權限。若需保留通話註冊，使用原 SIM 代碼。
目前尚未驗證可在此系統同時覆寫 MCC/MNC 與保留 IMS 的方法。

rc4 在每張 SIM 的目前值旁顯示電話 IMS 的註冊狀態與傳輸方式，可手動重新讀取。
三星 Android 17 若選擇不同於原訂閱的 SIM 電信業者代碼，會先顯示確認畫面。
在原代碼仍生效且選有顯示設定時，可選擇「僅套用國家碼與名稱」。
原有 MCC/MNC 覆寫功能可透過「繼續測試代碼」提交。已有覆寫時可用「還原設定」恢復原代碼。

IMS 狀態由每張卡的 Android ImsMmTelManager 讀取，權限不足或讀取逾時會顯示「無法讀取」。
[Android API 說明](https://developer.android.com/reference/android/telephony/ims/ImsMmTelManager)

## 真機驗證

- 兩卡免重啟還原原廠 SIM 代碼。SIM2 在 SIM1 仍維持覆寫時已重新註冊。SIM1 還原後
  到下一次成功註冊需要等待，期間曾短暫重連行動網路，無法據此判定重連是必要步驟。
- 沿用既有簽章覆蓋安裝 `1.1.5-rc4-s25`。以兩卡原先失敗的預設開啟確認畫面，
  選擇「僅套用國家碼與名稱」。兩卡的原代碼、APN 與選取逐欄符合套用前，兩卡的
  IMS 通話狀態都回報已透過行動網路註冊。原預設數據卡的綁定 DNS、HTTPS 204 通過。
- 簽署檔與手機安裝檔的雜湊一致，76 項單元測試、Lint 與建置通過。
