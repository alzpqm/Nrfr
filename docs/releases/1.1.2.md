# Nrfr 1.1.2 正式版

統一專案與 App 介紹，維護者署名使用 **Nrfr 維護團隊**。功能沿用 1.1.1。

- 更新 Android App 的關於頁面與功能說明。
- 更新桌面工具的介紹與作者欄位。
- 保留 Android 17、Shizuku 免 root、雙卡草稿隔離、回讀與還原功能。
- 支援 5／6 位 SIM 電信業者代碼、前導零與 177 組預設。

## 下載與升級

下載附件 `nrfr-1.1.2-release.apk`；`SHA256SUMS` 可用來核對檔案。此 APK 沿用 1.1.1 的固定發布簽章，可直接更新 1.1.1 正式版。

從 1.0.4／1.1.0 測試版升級時，請先在舊 App 還原設定、依提示重啟，再移除測試版並安裝正式版。

## 功能範圍

代碼修改針對 **SIM 電信業者代碼讀取值**，不修改訂閱資料、連線網路或基地台 MCC／MNC。其他 App 使用不同來源時，仍可能顯示原碼。詳見[MCC／MNC 使用說明](https://github.com/alzpqm/Nrfr/blob/master/docs/mcc-mnc.md)。

Android 16／17 使用臨時覆寫，重啟、換卡或系統重載後可能需要重新套用。解除安裝前請先還原設定並依提示重啟。
