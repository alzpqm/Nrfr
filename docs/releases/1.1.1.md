# Nrfr 1.1.1 正式版

支援 Android 17 與 Shizuku 免 root 操作，修正雙卡草稿隔離與設定結果顯示。

- 切換 SIM 後清空待套用輸入與前一張卡的操作結果。
- 重新讀取同一張 SIM 會保留尚未套用的草稿；還原後清空草稿。
- 分開顯示目前讀取值、待套用設定與上次操作結果。
- 支援 5／6 位 SIM 電信業者代碼、前導零、備份與還原。
- 提供 177 組預設與正體中文介面。
- 使用固定發布簽章及 R8 release 建置。

## 下載與升級

安裝附件 `nrfr-1.1.1-release.apk`；`SHA256SUMS` 可用來核對下載檔案。建議使用[最新正式版](https://github.com/alzpqm/Nrfr/releases/latest)。

從 1.0.4／1.1.0 測試版升級時，請先在舊 App 還原設定、依提示重啟，再移除測試版並安裝正式版。測試版與正式版簽章不同，無法直接覆蓋安裝；後續正式版沿用固定簽章。

## 功能範圍

代碼修改針對 Android 的 **SIM 電信業者代碼讀取值**，不修改訂閱資料、連線網路或基地台 MCC／MNC。其他 App 使用不同來源時，仍可能顯示原碼。詳見[MCC／MNC 使用說明](https://github.com/alzpqm/Nrfr/blob/master/docs/mcc-mnc.md)。

Android 16／17 使用臨時覆寫，重啟、換卡或系統重載後可能需要重新套用。解除安裝前請先還原設定並依提示重啟。

發布檢查包含單元測試、Lint、Android 與前端建置，以及 APK 簽章與校驗碼核對。裝置與系統版本可能影響功能可用性。
